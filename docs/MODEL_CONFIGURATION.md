# 模型配置

设置页面提供服务商、API地址、模型ID和密钥配置，支持 OpenAI兼容接口、Anthropic、DeepSeek、GLM和OpenRouter。模型ID可自行填写，推荐项不是实时可用模型列表。

## 权限与生效

这是平台全局模型配置，不是每个用户的私人模型账户。只有平台管理员可保存、恢复或发起连接测试；默认首个注册用户为管理员，可用服务端 AI_CONFIG_ADMIN_EMAIL 明确指定管理员。其他登录用户只读状态。

保存覆盖平台后续AI请求的配置，不改写.env。恢复环境配置只删除本地覆盖配置，不删除环境变量。运行或暂停的自主开发任务存在时拒绝保存/恢复，避免同一任务中途切换模型。连接测试不自动保存配置，也不自动在页面加载时触发。

## 密钥

密钥字段始终为空，页面只显示是否已有密钥。留空仅保留当前所选服务商已有密钥；切换到没有配置密钥的服务商必须在表单输入。接口不回显密钥，不返回上游原始错误正文。

配置保存在被Git忽略的 .local/ai-config.json。密钥用服务端 AUTH_SECRET 派生的密钥加密。备份/迁移应同时妥善保管该文件与AUTH_SECRET；更换AUTH_SECRET后旧密钥无法解密，需要重新配置。Unix限制文件权限，Windows仍依赖当前用户目录的NTFS权限，加密不能替代访问控制。

## 连接测试

用户明确点击后发送很短的真实模型请求，可能产生少量费用。测试成功仅证明当时地址、密钥与模型可进行一次请求，不证明长代码生成速度、结构化输出能力、配额充足或完整项目可交付。

本轮实现验证使用模拟请求，不自动访问用户配置的服务地址，不主动替换当前模型。全项目 TypeScript、ESLint 通过，21个测试文件252个测试通过，新增配置与路由测试覆盖加密读写、篡改/密钥轮换、权限、服务商密钥选择、配置恢复、活动任务阻止变更及连接测试超时。

现有服务 /settings HTTP请求可响应；未做已登录浏览器端到端验证，也未执行真实模型连接测试。代码未自动提交。
