```bash

```

## 唯一产品阶段

阶段键兼容已有数据库，未执行迁移或重置：

1. `topic`：选题规划
2. `requirements`：需求分析
3. `architecture`：架构设计
4. `design`：界面设计
5. `database`：数据库设计
6. `coding`：AI 开发
7. `testing`：测试验证
8. `deploy`：部署交付
9. `docs`：毕设文档
10. `defense`：答辩准备

标签、描述与路由集中在 `src/lib/projects.ts` 的 `STAGE_METADATA` 中。首页、项目概览、继续项目入口和子页面导航均复用这套定义。

界面设计复用已有开发工作区 `/develop?stage=design`，并非新增独立可视化设计器。自主开发、运行与预览、版本控制作为辅助工具，不额外计入阶段。阶段导航用于访问功能，不伪造阶段完成或修改已有项目进度。
