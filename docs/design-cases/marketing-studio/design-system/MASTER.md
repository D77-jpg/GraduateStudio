# 纸页 Papertrail · 营销创作工作台

主题：以商品事实为依据的营销创作与审核工作台，让每一句卖点可追溯，而不是营销落地页。
用户：维护商品资料的 creator、产出渠道文案的 creator、核实内容与配图的 reviewer，以及管理规则与权限的 admin；预览只是角色工作流示意，不模拟鉴权。
主任务：检查商品图片和事实缺项，选择商品与渠道创作候选，对照事实快照审阅文案，处理审核队列并保留版本关系。
布局：左侧轻量流程导航；商品页用图片资料卡+固定事实检查栏；创作页用商品事实窄栏+渠道文案宽栏；审核页用待办队列+内容与事实对照面板。主操作贴近对象，不放大 hero 或 KPI 卡片。
反模板：不把商品压成无图通用表格，不用默认紫渐变、营销口号或仪表盘数字；图片、缺项、禁用表述、版本和命中定位构成视觉层级。每页只强调一个业务动作，品牌来自暖纸色、深松绿和编辑式细线。
字体：正文与标题均采用 system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", "Microsoft YaHei", sans-serif；本地系统中文优先，未下载字体。正文 14px/1.65，正文预览 16px/1.9，页标题 26px/1.3，辅助文字不低于 12px。编码使用 ui-monospace, monospace。
配色：背景 #F6F5F0（暖纸工作台）；正文 #243831；主操作 #275E4A（深松绿）。补充语义只在此文档/CSS 定义：面板 #FFFFFF、次文字 #5C6D64、边线 #D8DED5、警示底 #FFF1D8/文字 #805119、错误底 #FBE8E4/文字 #9C3E31、已核对底 #EAF2E9/文字 #275E4A。警示始终配文字，不靠颜色传意；浅色背景不可用于白字按钮。

## 业务约束与真实读取来源

只读用户项目 `.workspace/cmv9krh9p0001ub64kc0o8bse/client/src/` 中 `router/index.js`、`views/products/ProductListView.vue`、`views/generation/GenerationConfigView.vue`、`views/content/ContentWorkspaceView.vue` 的路由/页面代码；未读取 .env。并未对用户项目作任何修改。

- `/products` 存在名称、SKU、目标人群、规格、卖点、图片数、在用/归档与生成入口。卡片是建议呈现，不宣称接口已有封面 URL。

## 状态、响应式与无障碍

- 本地示例所有页面持续标识“设计提案·示例数据·非业务系统”；生成、提交、通过、退回按钮只解释流程，不声称保存、联网、真实成功或调用付费模型。
- 1100px 以下事实栏随内容换行；760px 以下导航横排、双栏变单栏、队列在详情上方。320px 起容器可收缩，不强制横向表格。
- 所有图标为 inline SVG，装饰图形 aria-hidden；图片是 CSS 占位，显式标“CSS 图片占位 · 非商品实拍”。正式接入时需要替代文字和授权资源。
- 使用原生按钮、可见 label、aria-current、hidden 页区域、可见键盘 focus。通知区 aria-live=polite；切页焦点移至标题；不设置自动消失的错误通知。
- 加载、空、失败应保留筛选条件，并有重试入口；没有数据不可用示例图伪装已上传。正式权限仍由原应用守卫及后端控制。
