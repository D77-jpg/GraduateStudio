# 商品资料 /products

## 主任务
根据商品图片和事实缺项，决定补资料或进入创作，不用无意义 KPI。商品为示例，完整度是提案的前端检查，不是现有接口字段。

## 布局
页头简短说明事实是生成依据；下方名称/SKU 搜索和全部/待补充筛选；主体为 2 列图片卡片，图片区域约 160px，下面显示名称、SKU、人群、事实条目和缺项提示。右侧事实栏显示选中商品的规格、卖点、人群、图片与禁用表述，用“已提供/待补充”而非空进度条表达。桌面卡片宽栏与事实窄栏约 2:1。

## 关键交互
选择商品更新详情且保留筛选；搜索支持名称与 SKU；无匹配时显示真实空状态与清除入口。待补充筛选只过滤演示样本。查看资料/新建/补充弹出说明“提案示意，未保存”。“使用此商品创作”切到创作示意并带上商品上下文。正式实现遵守 creator/admin 编辑权限；图片主图 URL 需先确认接口，不能以 asset_count 冒充真实图片。

## 响应式和无障碍
1100px 以下右栏下移；760px 以下图片卡单列、筛选垂直排列；320px 不横溢。卡片使用原生选择按钮而非可点击 div；图片占位有可见说明；数量和状态以文字呈现。加载骨架不可带虚构商品名；失败允许重试；筛选无结果保留搜索词。
