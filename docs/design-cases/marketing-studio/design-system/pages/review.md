# 内容审核 /content

## 主任务
从待审队列选择内容，对照提交版本的事实快照、定位规则命中并给出人工意见。

## 布局
左栏为商品名+渠道+版本+风险摘要的可选队列；右侧并排文案正文与事实依据，底部审阅意见与通过/退回。高风险先被看到，但不把自动检查当合规结论。无 KPI、无排行榜。风险命中标注具体文本、问题与建议，版本号与事实快照常显。

## 关键交互
选择待审项更新版本、文案和风险；命中“定位”滚动到标记文本并给提示。本地通过/退回只解释真实流程，不修改样本状态，不宣称已保存。退回示意要求填写非空意见；正式系统应校验 reviewer/admin 权限、审核期版本锁定、已通过版本变更后重新审核。正式保留双版本 diff、多候选来源、规则检查详情与操作记录。

## 响应式和无障碍
窄屏队列在上、正文与事实串行、操作按钮换行；不让固定底栏遮住意见。可见选择状态配 aria-pressed；命中用 mark 和文字，意见有 label；通过与退回不只靠绿红区分。空队列说明暂无待审，不补示例任务；错误保留当前版本并允许重试。
