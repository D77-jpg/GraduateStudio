# 文案创作 /generation

## 主任务
依商品事实选择渠道与语气，比较候选文案后送审；不能让模型补全缺失事实。

## 布局
顶部显示当前商品与可追溯提示；左栏为 CSS 图片占位、事实摘要和禁用表述，右栏为渠道/语气配置与文案排版预览。候选按 01/02 切换，不用通用表格。真实系统模型、temperature、max_tokens、提示词预览与幂等标识应收进“高级配置”，不删除。

## 关键交互
本地选择渠道更新预览渠道标签，选择候选更新标题/正文。编辑区 input 即时更新“本地未保存”的预览。生成/保存/送审都仅展示说明，明确无网络/无存储/无付费模型；不能新增真实队列或伪称生成成功。返回商品选择保留当前上下文；选择不完整商品时展示缺项，正式生成应沿用现有 canSubmitText/required_facts 的业务判断，不仅凭提案完整度阻断。

## 响应式和无障碍
760px 下事实栏先于文案，正文宽度不超过 66 字符，label 关联输入框；候选按钮 aria-pressed 表示选中；状态更新由 aria-live 通知。长文案自然折行，不截断关键信息。真实任务提交后转任务状态页；失败保留配置及可重试说明。
