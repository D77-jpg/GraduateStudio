# 创作到审核的联合作业说明

本文件补充跨页审阅流程；可被 collectDesignEvidence 采集的页面规范位于 `../design-system/pages/creation.md` 与 `../design-system/pages/review.md`，不要在 design-system/pages 下嵌套目录。

1. 商品资料是唯一事实来源。示例缺失“材质”时不能在创作文案中推断材质，也不能因图片看起来像金属就补写“不锈钢”。
2. 创作选择商品、渠道、语气与候选。正式生成异步返回任务标识并保存事实快照；预览中没有生成请求，仅本地手写样本文案。
3. 编辑必须产生新版本，并保留来源。审核查看提交版本与当时快照，不能拿后来更新的商品档案代替历史事实。
4. 规则命中定位只是辅助，未命中不等于可发布。涉及外观、图中文字、功效等仍需人工核实。
5. reviewer/admin 按原权限审核；退回说明原因；通过后修改需重新审核；正式导出仅采用已批准版本。
6. preview.html 中所有提交/保存/通过/退回均为解释性反馈，刷新会重置本地编辑；没有业务接口、浏览器存储或模型调用。
