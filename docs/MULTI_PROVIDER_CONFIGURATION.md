# 多供应商模型配置

模型配置可保存多份供应商/模型/接口地址配置，分别保存密钥，并显式选择当前使用的配置。保存编辑与切换使用分开，切换前仍检查活动任务。旧单供应商加密配置自动读取为一份配置，不丢失此前反代设置。

## 使用方式

在设置的模型配置页新建配置，填写名称、供应商、模型、接口地址和密钥。可保存而不启用；选择已有配置编辑，空密钥仅表示保留该配置同一供应商同一地址的密钥。修改接口或供应商需重新填写密钥，不得借用其它配置密钥。

点击使用此配置后，后续请求使用选中的配置。测试连接仅在明确操作和确认后发送小请求；保存/切换不会测试、不恢复或启动生成任务。

DeepSeek官方配置使用deepseek供应商、deepseek-chat模型和https://api.deepseek.com地址（OpenAI兼容Chat Completions）。不是反代中的deepseek-flash名称。

## 安全

密钥加密保存在忽略版本控制的.local/ai-config.json，使用AUTH_SECRET派生加密密钥。API仅返回hasApiKey，不返回密钥或掩码片段；界面不预填密钥。

用户曾在会话中发送密钥，应在服务商控制台轮换。文档和源码不包含真实密钥。删除配置/恢复环境配置不等于撤销服务商密钥。
