# 大代码输出解析与恢复

针对模型正常stop并返回约10万字符、但代码JSON无法解析导致停机的场景改进。

## 安全提取

从完整外层对象、围栏或带说明的返回中提取完整JSON，并结合调用方Schema选择结果。不得通过乱补引号、修改转义、删除文件条目或拼补残缺代码“修好”输出。多个不同的可用结果不得任意取一个。保留字符串内容原样，避免嵌入代码的括号或围栏误导提取。

失败只记录安全结构诊断和数字位置，不记录完整输出、密钥或上游原始异常。

## 自动恢复

仅实现生成阶段的结构化输出失败或超时、且尚未创建/应用变更集时拆小批次。稳定文件索引身份保护旧变更集匹配；已写入或待确认的批次不能重排。拆分可持续到单文件，而非限制项目规模。单文件仍失败则保留断点并明确实际原因，不无限重复同样收费请求。

历史失败在用户再次继续时可按同样条件恢复；模块计划尚未保存时不把规划失败误当代码批次失败。

## 验证边界

模拟测试验证大JSON、嵌入围栏与括号、精确保留代码、拒绝损坏与歧义、拆批身份和已写入保护。全项目32个测试文件437个测试通过，最终相关92个测试通过，TypeScript及ESLint通过。本次不自动继续任务、不主动调用用户模型或修改已生成项目文件。改进不保证模型后续每次都输出正确格式。
